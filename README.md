# Aor-Au Smart Watch (Flask + SQLite)

## วิธีรัน
    pip install -r requirements.txt
    python app.py
เปิด http://127.0.0.1:5000  (ข้อมูลเก็บในไฟล์ shop.db — ปิด cmd แล้วเปิดใหม่ข้อมูลยังอยู่)

## ADMIN
ไม่มีลิงก์ ADMIN บนหน้าเว็บ — ไปที่หน้า "เข้าสู่ระบบ" ของลูกค้า พิมพ์ `/gamemode 1` ในช่องชื่อผู้ใช้ แล้วกดเข้าสู่ระบบ จะขึ้นหน้าล็อกอิน ADMIN
(เปิดค้างได้ 10 นาที / เปลี่ยนคำสั่งที่ ADMIN_SECRET_CMD ใน auth.py)
ID/รหัสผ่านตั้งที่ config.py (ADMIN_USERNAME / ADMIN_PASSWORD) — ควรเปลี่ยนก่อนใช้งานจริง

## ส่งอีเมลผ่าน Gmail (ไม่บังคับ)
1. เปิด 2-Step Verification ในบัญชี Google แล้วสร้าง "App Password" 16 หลัก
2. ก่อนรัน (Windows):  set SMTP_USER=tanakornousonean@gmail.com  และ  set SMTP_PASS=รหัส16หลัก
ถ้าไม่ตั้งค่า ระบบจะพิมพ์ข้อความ [MAIL-DEMO] ลงหน้าจอแทนการส่งจริง

## เมนูหลังบ้าน ADMIN (แบ่งกลุ่ม)
- 📊 ภาพรวม
- 🛒 ระบบขายของ: จัดการสินค้า / หมวดหมู่สินค้า / คำสั่งซื้อ-ตรวจสลิป / ลูกค้า

## ตรวจสอบการชำระเงิน (ADMIN อนุมัติ/ปฏิเสธ)
ลูกค้าแนบสลิปแล้วสั่งซื้อ -> ออเดอร์เป็น "รอตรวจสอบ" (สต็อกถูกจองไว้) -> ADMIN เข้า คำสั่งซื้อ / ตรวจสลิป -> กด "ตรวจสลิป" ดูรูปสลิปเทียบกับยอดที่ต้องได้รับ
- อนุมัติ: สถานะ = ชำระเงินแล้ว, ลูกค้าพิมพ์ใบเสร็จได้, นับเข้ายอดขาย, ส่งอีเมลแจ้งลูกค้า
- ปฏิเสธ: ต้องใส่เหตุผล, คืนสต็อกอัตโนมัติ, ลูกค้าเห็นเหตุผลและได้รับอีเมล
- ตัดสินแล้วเปลี่ยนไม่ได้ / ออเดอร์เก่าที่เป็น "ชำระเงินแล้ว" ก่อนมีระบบนี้ ถือว่าอนุมัติแล้ว
- 🎨 ระบบแต่งเว็บ: แบนเนอร์ / วิดเจ็ตหน้าแรก / คอมเมนต์หน้าแรก
- 💰 ข้อมูลรายได้: ยอดขายรายวัน
- ⚙️ บัญชีและหน้าร้าน: โปรไฟล์ของฉัน / เปิดหน้าร้าน
